# Student Performance Analyzer

This is my first Python project, built to practice and apply the basics of Python in a real-world style application.

The Student Performance Analyzer takes a student's details and marks, then calculates their overall performance and generates a simple result report.

## What the Project Does

- Takes student name and roll number
- Takes marks for DSA, OOP, and Maths
- Checks whether the entered marks are valid
- Handles incorrect inputs without crashing
- Calculates total and average marks
- Assigns a grade based on the average
- Shows overall performance
- Shows PASS or FAIL status
- Finds the highest-scoring subject
- Finds the lowest-scoring subject
- Shows performance for each subject
- Generates a short performance summary
